# Governor — brand

Pre-1.0; expect revisions.

The brand is in transition: the original mark (a tick inside a circle) is
being retired in favour of the **gov face** emotion suite, which doubles as
the in-product status indicator. See `gov-face-cycle.svg` for the canonical
animated lockup and `server/{worker,node}/src/_gov-faces.ts` for the static
`FACE_OK` / `FACE_PENDING` variants used by the public sign-off page.

## Usage rules

1. **Clearspace.** Leave space equal to half the face's height on every
   side. The face needs room to read as a character, not as decoration.
2. **Don't stretch the face.** The viewBox is square (160×160) and the
   internal proportions are tuned. Render at a square aspect only.
3. **Don't recolour the face card.** The dark card + light face is the
   contrast pairing that lets the face register at small sizes. Tint the
   accent (Jade / Rust) elsewhere on the page if you need brand colour.
4. **Don't add a drop shadow** to the face or the wordmark. Both are
   geometric; shadows make them look like buttons.
5. **Wordmark vs face.** Use the face as the mark (favicon, app icon,
   header avatar). Use `logo*.svg` when you specifically need the word
   "Governor" rendered. Don't manually re-create the old tick+wordmark
   lockup — the face is the mark now.

## Colour

The mark itself is colour-neutral. If you need a brand colour for
accents, posters, or marketing, use one of these:

- **Slate** `#1a1a1a` — default on light surfaces
- **Bone**  `#e8e6df` — default on dark surfaces
- **Jade**  `#1f6f5c` — accent / "allow" decisions
- **Rust**  `#b04a2a` — accent / "deny" decisions (use sparingly)

The CLI styling uses these for its `ALLOW` and `DENY` banners.

## Regenerating the legacy PNG set

Applies to the pre-pivot tick mark only. The `png/` directory still
ships those PNGs so external favicon consumers don't 404. Face-based
replacements will be cut in a follow-up. To rebuild the legacy PNGs
from `favicon.svg`:

```sh
# librsvg (recommended; brew install librsvg)
cd governor/brand
for s in 16 32 48 180 192 512 1024; do
  rsvg-convert -w $s -h $s favicon.svg -o png/favicon-${s}.png
done
cp png/favicon-180.png png/apple-touch-icon.png

# ImageMagick alternative
for s in 16 32 48 180 192 512 1024; do
  magick -background none -resize ${s}x${s} favicon.svg png/favicon-${s}.png
done
```

The SVG sources are the canonical assets; the PNGs are derived. If
you change the mark, regenerate the PNG set *and* re-embed
`apple-touch-icon.png` into the worker (`server/worker/src/index.ts`,
`APPLE_TOUCH_ICON_PNG_B64`) with:

```sh
base64 -i brand/png/apple-touch-icon.png | tr -d '\n'
```
